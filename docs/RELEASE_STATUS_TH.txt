ยังไม่พร้อม Production ด้วยเหตุผลต่อไปนี้:
- Transfer Data to QAC (Register Task -> Upload -> Complete -> View -> Judge PASS -> Checked -> OK -> Close) ยังไม่ได้พัฒนา/ทดสอบ E2E บน QAC จริง ห้ามกดบันทึกอัตโนมัติหรือเชื่อว่าโค้ดนี้มีฟังก์ชันดังกล่าว
- GUI Runtime บน Windows/PySide6 ยังไม่ได้ทดสอบ (สภาพแวดล้อมปัจจุบันไม่มี PySide6)
- การนับ Reject ต้องตรวจตัวอย่าง Excel/CSV หน้างาน โดยเฉพาะรูปแบบข้อความที่คอลัมน์ท้ายและเงื่อนไขไม่ให้บวกซ้ำ
- Access CSV Editor ยังไม่มีระบบ audit per-field, file change-detection หลังโหลด, session expiration และ PIN ที่ฝังในโค้ดไม่ทนต่อผู้โจมตีที่แก้ไฟล์ได้
- สถานะ QAC, Login, Upload, Judge, Confirm ต้องทดสอบด้วยบัญชีทดสอบและข้อมูลทดสอบที่ได้รับอนุญาต
